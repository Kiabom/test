## کار
1. `components/hardware/`: `TruckSvg` (نماهای side/top/front/rear/under، خالی/پر، رنگ کابین)، `CameraFeed` (طبق HARDWARE_MOCKUPS §۳: صحنه، نویز `feTurbulence`، اسکن‌لاین، timestamp زنده، REC، کادر تشخیص رنگی با confidence، حالت شب و NO SIGNAL، seed قطعی)، `ScaleDeckTop` (باسکول از بالا، ۸ لودسل، ۴ پرتو IR، ماسک ROI، کامیون در موقعیت داده‌شده).
2. `/app` داشبورد طبق وایرفریم: فیلترها، ۸ KPI اصلی + KPI ثانویه، نمودارها (Recharts): ناحیه تناژ ساعتی + خط هدف، دونات مواد، ستونی ورود/خروج، gauge هدف شیفت، قیف جریان؛ جدول آخرین سفرها (با thumbnail دوربین)، هشدارهای باز، پنل ریسک، تفکیک شعبه/اپراتور/حمل‌کننده. همه با `useLive` بروز و «آخرین بروزرسانی». داده ناکافی → «—».
3. `/app/live` اتاق کنترل (تم تیره پیش‌فرض این صفحه): ۴ کارت لاین (A، B، C، E) با فید، پلاک، RFID، تصمیم، وزن LED، چراغ و راهبند زنده؛ شبکه ۲×۲ دوربین قابل انتخاب؛ کنسول لاگ خام (monospace، اسکرول زنده، رنگ بر اساس نوع)؛ جداول «داخل سایت» و «اخیراً خارج‌شده»؛ صف و استثناها.
4. `/app/site-map`: نقشه SVG سایت (جاده، پارکینگ، لاین‌ها A–E، باسکول‌ها، گنتری LiDAR، محوطه بارگیری با لودرها، اتاقک‌ها)؛ marker کامیون‌ها با حرکت بین ایستگاه‌ها مطابق state، رنگ دستگاه‌ها بر اساس وضعیت، کلیک → Drawer جزئیات.
5. `/wallboard`: تمام‌صفحه تیره، KPIهای بزرگ، صف، آخرین محموله‌ها، هشدارها؛ بدون shell.
