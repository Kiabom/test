# فاز ۰۹ — سلامت تجهیزات و کالیبراسیون، ماژول‌های معدنی، گزارش، صورت‌حساب، یکپارچه‌سازی، مدیریت، شبیه‌ساز

> مرجع: `spec/SCREENS.md` (۱۷–۲۵)، `spec/FEATURES.md` M6–M8.

## کار
1. `/app/devices` تب‌ها:
   - **رجیستری:** کارت هر دستگاه (SVG کوچک از کاتالوگ، نوع، IP، پروتکل، firmware، وضعیت، heartbeat نسبی زنده)، دکمه «Test Read» (نمایش آخرین فریم/خوانش)، دکمه آفلاین کردن (دمو).
   - **سلامت باسکول:** نمای بالای باسکول با ۸ لودسل و heatmap انحراف، جدول هر سلول (zero، drift، noise، دما، ولتاژ، وضعیت)، نمودار drift ۳۰ روز؛ برای باسکولی که diagnostics پشتیبانی نمی‌کند: «پشتیبانی نمی‌شود» (نه سالم)؛ دکمه «درخواست سرویس» (پیوست ۳۰ روز تله‌متری ماک).
   - **کالیبراسیون:** گواهی‌ها (شماره، صادرکننده، تاریخ، اعتبار، نقاط تست با خطا، hash سند)، تقویم/timeline انقضا، وضعیت VALID/EXPIRING/EXPIRED، قفل legal (S-CAL-EXP)، ثبت گواهی جدید (فقط نقش تعمیرات).
   - **Edge Gateway:** آنلاین/آفلاین، عمق صف sync، تأخیر، آخرین sync، دکمه شبیه‌سازی قطع WAN.
2. `/app/modules/lidar`: فهرست اسکن‌ها، PointCloudViewer، روند حجم روزانه، «چگالی تخمینی = وزن باسکول / حجم» با برچسب، هشدارهای R31–R33.
3. `/app/modules/payload`: نمایشگر کابین لودر ماک (سطل‌ها با وزن، هدف/واقعی، نوار پیشرفت)، صف کار لودر (کامیون‌های منتظر با ماده/هدف)، جدول اختلاف payload با باسکول (R34)؛ برچسب «تخمینی».
4. `/app/modules/fleet`: سفرهای شیفت، هیستوگرام cycle time، Gantt چرخه کامیون‌ها (load/haul/queue/dump/return)، idle/queue، fuel = N/A (داده تله‌متری موجود نیست)، سه جمع جدا (فروش / ارسال سایت / جابه‌جایی داخلی)، بخش «بانکر و دوزینگ» فقط‌خواندنی (سطح بانکر ۸۰/۱۲۰/۲۴۰ تن، نرخ خوراک، دستور فعلی) با برچسب «PLC مالک setpoint است».
5. `/app/reports`: قالب‌ها (Daily Close، شیفتی، مشتری، ماده، حمل‌کننده، خودرو، سفرهای کامل/ناقص، هشدارها، دقت ANPR/RFID روز/شب)، فیلترها، پیش‌نمایش جدول + نمودار، خروجی CSV/XLSX/PDF (چاپ)، فرم زمان‌بندی ایمیل (ماک → outbox)، دکمه «بستن روز» (Daily Close با خلاصه و قفل).
6. `/app/billing`: صورت‌وضعیت مشتری (تیکت‌های تأییدشده × قیمت ماده − کسر)، فاکتور پیش‌نویس قابل چاپ، وضعیت ارسال به ERP.
7. `/app/integrations`: outbox ERP (فیلتر وضعیت، retry، replay، مشاهده payload JSON)، dead-letter، webhooks (فهرست ماک + آخرین تحویل)، API keys (ماک، ماسک‌شده)، نگاشت فیلدها. `/app/notifications`: صندوق SMS/WhatsApp/Email با متن و وضعیت تحویل.
8. `/app/admin`: کاربران، ماتریس RBAC (نقش × مجوز با تیک)، شعب، شیفت‌ها (شامل C عبوری از نیمه‌شب)، تنظیمات (freshMs، ارقام، تم پیش‌فرض)، feature flag ماژول‌ها، سطح اشتراک فعلی.
9. `/app/simulator`: سرعت، خودکار/دستی، دکمه همه سناریوهای MOCK_DATA §۶ با توضیح نتیجه مورد انتظار، فهرست دستگاه‌ها با سوییچ آنلاین/آفلاین، ریست داده، لاگ رخدادهای شبیه‌ساز.
