# ماکاپ سخت‌افزار و چیدمان سایت

> همه تجهیزات در نمونه **شبیه‌سازی** می‌شوند و با **SVG اختصاصی** نمایش داده می‌شوند (`web/src/components/hardware/*`). هیچ فرمان واقعی به PLC ارسال نمی‌شود. نام برند تجهیزات «عمومی» است (مثلاً «دوربین ANPR صنعتی IP67»)، نه مدل تجاری خاص.
> اختیاری در محیط شما: می‌توان عکس‌های CC0 (Wikimedia Commons / Unsplash) دانلود و در `web/public/media/` قرار داد و منبع را در `web/public/media/CREDITS.md` ثبت کرد. از تصاویر سایت رقبا استفاده نکنید.

## ۱. چیدمان سایت نمونه (معدن سنگ آهن — «سایت مرکزی»)

```
   ورودی جاده ─►  [پارکینگ انتظار / صف]  ─►  لاین A: دروازه ورود  ─►  لاین B: باسکول ۱ (ورودی)  ─►  محوطه بارگیری (لودر/شاول، دپو)
                    تابلو فراخوان LED            ├ دکل ANPR جلو+عقب            ├ دوربین جلو/عقب/بالا/جانب           ├ لودر L-01..L-03
                                                  ├ آنتن RFID UHF               ├ IR موقعیت ۴ نقطه + ROI تصویری     └ شاول SH-01
                                                  ├ دوربین نما + عکس گواهینامه   ├ indicator + junction box
                                                  ├ UVSS زیر خودرو               ├ مانیتور بزرگ راننده + چراغ
                                                  └ راهبند + چراغ                 └ کیوسک + چاپگر
   ◄─ خروجی جاده  ◄─  لاین E: دروازه خروج  ◄─  لاین D: اسکنر LiDAR گنتری  ◄─  لاین C: باسکول ۲ (خروجی)  ◄─┘
                      ├ اسکن QR حراست (موبایل)    ├ اسکن بالا 3D                ├ مثل باسکول ۱
                      ├ ANPR + RFID              └ تشخیص روکش/بار بیرون‌زده
                      └ راهبند + چراغ + آژیر
```

## ۳. فید دوربین ساختگی (`CameraFeed`)
- لایه‌ها: پس‌زمینه گرادیان (روز/شب)، زمین خاکی، کامیون `TruckSvg` از زاویه مربوط، پلاک `IranPlate` روی کامیون، نویز SVG (`feTurbulence`)، اسکن‌لاین، vignette.
- Overlay: نام دوربین (مثلاً `CAM-A-FRONT`)، timestamp زنده، `● REC`، کادر تشخیص (سبز ≥0.85، زرد 0.6–0.85، قرمز <0.6) + برچسب «ANPR 96%».
- حالت شب: سیاه‌وسفید با درخشش IR. حالت offline: «NO SIGNAL» + زمان آخرین فریم.
- قطعی بودن: `seed` هر Evidence ثابت → همیشه همان تصویر.
