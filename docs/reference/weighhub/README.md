# مرجع تصویری WeighHub

این پوشه برای **اسکرین‌شات‌هایی است که خودتان از weighhub.com می‌گیرید** (سایت از محیط ساخت در دسترس نبود).

## چه چیزهایی را عکس بگیرید
1. صفحه اصلی `https://weighhub.com/en` (کامل، اسکرول‌شده)
2. `features` — هر ایستگاه (Stop 0 تا Add-ons)
3. `controls` — کنترل‌های 01 تا 10
4. `connect` و `pricing`
5. دموی فقط‌خواندنی `https://demo.weighhub.com/` — داشبورد، Gate log، Weighing، Tickets، Exit permits، Reports

## نام‌گذاری
`01-home.png`, `02-features-stop1.png`, … و در صورت امکان یک خط توضیح در `notes.md`.

## نحوه استفاده
به Claude Code بگویید: «اسکرین‌شات‌های `docs/reference/weighhub/` را بخوان و **چیدمان و جریان** صفحات معادل را با آن‌ها هماهنگ کن؛ برند، لوگو، متن و رنگ را کپی نکن.»

> یادآوری حقوقی: فقط الگوی تعامل و ساختار اطلاعات الهام گرفته می‌شود؛ هیچ دارایی بصری یا متنی WeighHub در محصول استفاده نمی‌شود.
