# سناریوی نمایش (۱۵ دقیقه)

آماده‌سازی: `cd web && npm run dev` (یا `npm run build && npm start`). دو پنجره مرورگر باز کنید: لپ‌تاپ برای اپ، و یک گوشی (یا DevTools در حالت موبایل ۳۹۰px) برای راننده و حراست. اگر می‌خواهید هر مرحله را خودتان انجام دهید، در `/app/simulator` حالت را روی **دستی** بگذارید؛ در حالت **خودکار** بازیگران مجازی همه‌چیز را جلو می‌برند.

## ۱. سایت معرفی — ۱ دقیقه
- `/` : روال سفر کامیون در ایستگاه‌های ۰ تا ۷، کنترل‌های ۰۱–۱۰، اسکن‌ها، اتصال سخت‌افزار، قیمت‌گذاری سه‌سطحی.
- دکمه «ورود به دمو زنده» → `/app`.

## ۲. داشبورد و اتاق کنترل — ۲ دقیقه
- `/app` : ورودی/خروجی امروز، حاضر در سایت، تیکت‌های معلق، هدف/واقعی شیفت، نمودار ساعتی، feed زنده و پنل ریسک.
- `/app/live` (پیش‌فرض تیره — حالت شب اتاق کنترل) : پنج لاین A–E، شبکه دوربین، وزن زنده با نشان پایدار/تازه، پلاک + RFID، راهبند و چراغ، لاگ خام دستگاه‌ها.
- `/display/B` را روی مانیتور دوم باز کنید: همان پیام‌ها با فونت درشت برای راننده.

## ۳. یک سفر کامل — ۵ دقیقه
1. `/app/simulator` → حالت **دستی**، سرعت ۲×، سناریوی **S-NORMAL**.
2. `/app/gate` : خواندن پلاک جلو/عقب، RFID، اسکن زیر خودرو، کارت تطبیق هویت و trace تصمیم دروازه (Safety → Identity → Documents → Permit). PASS → درخواست باز شدن و ACK از PLC.
3. پیامک ماک راننده را در `/app/notifications` نشان دهید و لینک `/d/[token]` را روی گوشی باز کنید: شماره نوبت، مرحله فعلی، دستور بعدی.
4. `/app/weighing` : وزن تا پایدار شدن نوسان دارد؛ دکمه Capture (یا F5) فقط وقتی فعال است که وزن پایدار، تازه (<۱۲s) و همه چرخ‌ها روی باسکول باشند. تارا ثبت می‌شود.
5. `/app/scan?tab=lidar` : ابر نقاط سه‌بعدی بار، نقشه ارتفاع، حجم و جرم «تخمینی»؛ `/app/modules/payload` نمایشگر کابین لودر.
6. توزین دوم روی باسکول ۲ → خالص، کسر مجاز، کنترل حواله؛ «نهایی‌سازی» → تیکت با QR و بارکد (`/print/ticket/[id]`) و مجوز خروج.
7. روی گوشی، `/app/guard` (نقش حراست): لینک/QR مجوز خروج را اسکن کنید → **مجاز**، راهبند خروج باز می‌شود. دوباره اسکن کنید → **غیرمجاز — این QR قبلاً استفاده شده** و هشدار بحرانی R36 در مرکز هشدار.
8. `/verify/[code]` : راستی‌آزمایی عمومی تیکت با حداقل داده.

## ۴. کنترل‌های ضدتقلب — ۳ دقیقه
- سناریوهای **S-MISMATCH** (پلاک ≠ RFID → HOLD)، **S-POSITION** (چرخ بیرون از باسکول)، **S-OVERWEIGHT**، **S-UVSS** (جسم مشکوک زیر شاسی) را اجرا کنید و نتیجه را در اتاق کنترل ببینید.
- `/app/alerts` : چرخه ACK → بررسی → حل با SLA؛ زبانه قوانین: تغییر پارامتر (نسخه جدید) و تست سایه روی ۷ روز گذشته.
- `/app/fraud` : تارای غیرعادی، خالص تکراری، سفر غیرممکن، نرخ ثبت دستی + کارنامه اپراتورها.
- `/app/audit` : «راستی‌آزمایی زنجیره» → سالم؛ «دستکاری» → دوباره راستی‌آزمایی → رکورد شکسته مشخص می‌شود؛ «بازگردانی».

## ۵. نگهداری و مدیریت — ۲ دقیقه
- `/app/devices` : heartbeat دستگاه‌ها، نقشه حرارتی لودسل و drift، تقویم گواهی کالیبراسیون. سناریوی **S-CAL-EXP** → باسکول ۲ قفل legal؛ «ثبت گواهی جدید» قفل را برمی‌دارد.
- سناریوی **S-OFFLINE** : WAN قطع، Edge ادامه می‌دهد و صف همگام‌سازی پر می‌شود؛ بعد از وصل، بدون تکرار ارسال می‌شود (`/app/integrations`).
- `/app/reports` : قالب‌ها، خروجی CSV/Excel/PDF، ایمیل زمان‌بندی‌شده، Daily Close. `/app/billing` صورت‌حساب از وزن قابل محاسبه.
- `/app/admin` : ماتریس RBAC، و از نوار بالا نقش را به «حراست» عوض کنید تا ببینید اقدام‌های غیرمجاز رد می‌شوند.

## ۶. جمع‌بندی — ۱ دقیقه
`/wallboard` روی تلویزیون سالن، `/display/queue` تابلو فراخوان، `/kiosk/B` کیوسک لمسی با راهنمای صوتی.

> بازنشانی داده برای اجرای دوباره: `/app/simulator` → «بازنشانی داده».
